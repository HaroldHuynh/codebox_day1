Design Skills:
Keep the style of the frontend simple, minimalistic, and focus on functionality over flare
The color theme should be white, black, and a nice professional and minimalistic shade of blue for accents.
For all buttons should be animated on hover in a minimalistic style that is not over the top.


API Skills:
When implementing a new API endpoint, run a test to test a normal path and run another test to test an error path to ensure that the endpoint responds as expected.
